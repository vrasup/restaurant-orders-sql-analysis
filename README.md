# Restaurant Orders SQL Analysis

## 📌 Project Overview
This project is a guided SQL analysis from Maven Analytics, where I explored restaurant order data to generate business insights.

## Objective
To analyze menu performance and customer ordering patterns using SQL.

##  Tools Used
- MySQL 

## Key Analysis Performed
- Identified most and least ordered items
- Analyzed category-wise performance
- Calculated revenue per order
- Found highest and lowest value orders

## Key Skills Practiced
- SQL Joins
- GROUP BY Aggregations
- Common Table Expressions (CTEs)
- Window Functions
- Analytical Thinking

## Key Insight
The analysis helped understand how different menu categories contribute to overall revenue and which items are most popular among customers.
